Wii U VC Image Builder is an independent community utility.

The project uses or interoperates with community projects and public metadata sources, including Libretro/RetroArch databases and GameTDB where applicable.

Optional artwork and boot-sound search connects to these community repositories:

UWUVCI Community Images
https://github.com/UWUVCI-PRIME/UWUVCI-IMAGES

Cucholix WiiVC BIS
https://github.com/cucholix/wiivc-bis

GameCube Inject Artwork
https://github.com/reddragon105/gamecube-inject-artwork

Libretro Thumbnails
https://github.com/libretro-thumbnails/libretro-thumbnails

MyInstants is available only as a console-specific external search opened in the user's browser:
https://www.myinstants.com/

Repository artwork and online repository audio are downloaded on demand. The selected source repository and matching evidence are written to metadata.txt. MyInstants-hosted audio is not scraped or bundled. Rights and licensing can vary by source, image and sound. Users must review the applicable source terms and file rights before downloading or redistributing content.

This release bundles only two original generic startup chimes created for the application. No MyInstants-derived console recordings are included in the source, Sharing Kit or generated executable. Per-game sounds selected with Browse are converted and stored privately under the user's active configuration directory. Set Console stores a private reusable console-wide choice in the same configuration structure.

Cucholix WiiVC BIS supplies optional generic console bootSound.btsnd files for supported systems where available. GameCube Inject Artwork supplies optional GameCube bootSound WAV files. The application converts selected WAV, MP3 and BTSND sources to bootSound.wav and does not grant redistribution rights for that audio.

RetroArch and Dolphin are separate projects and are not bundled with this release.
