Wii U VC Image Studio
====================

Extract this complete folder, then run Wii_U_VC_Image_Studio.exe.
Windows x64 and Microsoft Edge WebView2 Runtime are required. Python is not.
Use a writable application folder. Normal use does not require administrator rights.

Choose the Export folder, add your ROMs, select a game and import a screenshot
or search artwork. Configure RetroArch/Dolphin only for emulator capture.
Help in the application documents artwork, capture, audio and metadata controls.

Updates checks for new stable releases. Download and Install and restart are
separate explicit actions. Restart closes the current ROM list. Generated files
and saved settings are retained. Active operations block installation.

Existing settings remain in %APPDATA%/Wii_U_VC_Image_Builder or the custom
configuration folder already selected. Updater files use
%LOCALAPPDATA%/Wii_U_VC_Image_Studio/updates, not the application folder.
Keep the executable filename stable for shortcuts. Custom current filenames
are preserved by in-app updates. Image Builder v5.05 requires a manual first upgrade.

Builds are unsigned. A matching SHA-256 is an integrity check, not publisher signing.
Do not disable security software to run a blocked file. Review source rights before
redistributing downloaded artwork/audio. No ROMs or MyInstants audio are bundled.

Documentation, source, releases and troubleshooting:
