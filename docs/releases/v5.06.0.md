# Wii U VC Image Studio 5.06.0

First repository-maintained Studio build, based on user-confirmed Image Builder
v5.05. Preserves the authentic icon, viewport layout, preview detachment, framing,
metadata, captures, artwork matching, independent output assignments and audio.

- Stable Wii_U_VC_Image_Studio.exe filename and preserved legacy settings paths.
- Background stable-feed checks and explicit Download / Install and restart.
- Allowlisted downloads, digests, package identity, archive and PE validation.
- Target-volume staging, health acknowledgement and rollback helper.
- Source layout guard, clean source packaging, CI and read-first handoff.

Publication is gated on Linux/browser and Windows build/update checks. See
[validation](https://github.com/TechSavage1989/Wii-U-VC-Image-Studio/blob/main/docs/validation.md)
for performed checks and limits.
Unsigned Windows x64 build. No claims of publisher signing or universal Windows
compatibility. No prior published Studio release exists for a real historical
release-to-release upgrade test. v5.05 requires a manual first installation.
